Key concept

What is a Tiled (.tmx) map?

🖌️ Tiled = a map-drawing app

An artist paints the world in a free program called Tiled and saves it as a .tmx file — grass, water, buildings, doors, everything.

🐍 pytmx = the Python reader

tmx_importer() loads every .tmx file in data/maps/ into Python objects your game can loop through.

🧱 Tile layers

layer.tiles() gives you (col, row, image) for every tile — used for Terrain.

📦 Object layers

Rectangles with custom data — obj.x, obj.y, obj.properties['key']. Used for Water, Coast, Objects, Transition, Collisions, Monsters, Entities.

Key concept

Layers & the camera (recap + new)

Every sprite has a z layer. Sprites draw bottom-to-top:

top z=4
main z=3
bg z=1
water z=0

Camera = an offset. Every sprite is drawn shifted so the player always sits at screen-centre:
offset.x = -(player.centerx - WINDOW_WIDTH/2)

y_sort: on the main layer, sprites with a bigger y (lower on screen) draw on top — so you can walk behind a tree and in front of a fence.

AnimatedSprite — frames that loop 
class AnimatedSprite(pygame.sprite.Sprite):
  def __init__(self, pos, frames, groups, z=3):
    self.frame_index = 0
    self.frames = frames
    super().__init__(groups)
    self.image = self.frames[0]
    self.rect = self.image.get_frect(topleft=pos)

  def animate(self, dt):
    self.frame_index += ANIMATION_SPEED * dt
    self.image = self.frames[
      int(self.frame_index % len(self.frames))]

🎞️ Just like a flipbook! A list of images, and every frame we move a tiny bit further through the list.

% (modulo) wraps back to frame 0 when we reach the end — the ripple never stops.

Used for both water and coast foam in setup().

MonsterPatchSprite — tall grass 
class MonsterPatchSprite(AnimatedSprite):
  def __init__(self, pos, frames, groups,
               biome, monsters, level):
    z = 3 if biome != 'sand' else 1
    super().__init__(pos, frames, groups, z)
    self.y_sort -= 40
    self.biome = biome
    self.monsters = monsters.split(',')
    self.level = level

🌿 These are the grass patches where wild monsters could jump out — one patch can hold several possible monsters, split from a string like 'Atrox,Pouch'.

Sand patches draw behind the player (z=bg) so footprints look right; grass draws at z=main.

⚠️ Tiled gives one image, not a list — wrap it: [obj.image] so AnimatedSprite is happy.

TransitionSprite — an invisible doorway 
class TransitionSprite(pygame.sprite.Sprite):
  def __init__(self, pos, size, target, groups):
    super().__init__(groups)
    surf = pygame.Surface(size)
    self.image  = surf
    self.rect   = surf.get_frect(topleft=pos)
    self.target = target  # (map_name, spawn_point)
    self.hitbox = self.rect.copy()

🚪 This sprite is never drawn — it's not added to all_sprites, only to transition_sprites. It's a trigger zone, not a picture.

target is a tuple: which map to load, and which spawn point to appear at — e.g. ('house', 'world').

🌳 Treetop trick: a tree's trunk is main (behind the player when walking past), but its leafy top is a separate 'top' object drawn in front — that's how you can walk "into" a tree canopy.

transition_check() — and a REAL bug we found! 
def transition_check(self):
  sprites = pygame.sprite.spritecollide(
    self.player, self.transition_sprites, False,
    collided=lambda a, b:
      a.hitbox.colliderect(b.hitbox))
  if sprites:
    self.player.block()
    self.transition_target = sprites[0].target
    self.tint_mode = 'tint'
❌ default: compares .rect
✅ fixed: compares .hitbox

🐛 spritecollide() checks .rect by default — the player's whole sprite frame (128×128), way bigger than the real hitbox!

🔍 What actually happened: without the fix, doors triggered from tiles away — and walking into the hospital would instantly bounce you back outside, because your oversized rect already touched the exit door the moment you spawned inside! Passing collided= fixes both problems at once.
