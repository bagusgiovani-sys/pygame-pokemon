⚠️ Diagonal problem

UP + RIGHT = (1,1) — length 1.41 — player is 41% faster diagonally!

Fix: input_vector.normalize() rescales to length 1.

✅ Always check for zero

normalize() on (0,0) crashes with division by zero.

Guard it: v.normalize() if v else v

def __init__(self, duration, repeat=False, autostart=False, func=None):
    self.duration = duration; self.start_time = 0; self.active = False
    self.repeat = repeat; self.func = func
    if autostart: self.activate()

def activate(self):    self.active = True; self.start_time = get_ticks()
def deactivate(self):  self.active = False; self.start_time = 0
                       if self.repeat: self.activate()
def update(self):
    if self.active and get_ticks() - self.start_time >= self.duration:
        if self.func: self.func()
        self.deactivate()

⚠️ Call timer.update() every frame — the NPC patrol in session 3 uses Timer(1500, repeat=True).

# Step 7 — read keyboard
def input(self):
  keys = pygame.key.get_pressed()
  v = vector()
  if keys[K_UP]:    v.y -= 1
  if keys[K_DOWN]:  v.y += 1
  if keys[K_LEFT]:  v.x -= 1
  if keys[K_RIGHT]: v.x += 1
  self.speed = 250
  self.direction = v.normalize() if v else v
# Step 8 — move x then y (two-pass)
def move(self, dt):
  self.rect.centerx  += self.direction.x * self.speed * dt
  self.hitbox.centerx = self.rect.centerx
  self.collisions('horizontal')     # resolve x
  self.rect.centery  += self.direction.y * self.speed * dt
  self.hitbox.centery = self.rect.centery
  self.collisions('vertical')       # resolve y

Why two passes? Corner hits are unambiguous — x resolves first, then y. Player slides along walls instead of getting stuck.

What you learned

  • The Timer class: activate → count → expire → call func → deactivate
  • get_pressed() = held key every frame  ·  get_just_pressed() = one frame only
  • Move x first, resolve, then y — corners resolve cleanly
  • The hitbox is smaller than the sprite — feet-only collision
